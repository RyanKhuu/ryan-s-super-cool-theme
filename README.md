# Ryan's Super Cool Theme

Hello this is a theme that I made for my own personal use because the theme's I've used in the past never fully matched what I liked. I highly recommend anyone that want to create their own theme to do so as its a fun small challenge but it's also something you can always tailor to what you need at anytime.

### Colour Types:
I tried to be consistent with colours and what they represent but there are some exceptions, I currently have test it with: C, Python, and Javascript. Other languages I have not tested it with and will so as I pick them up.

1. Purple - Data Types (int, double, custom_data_types)
2. Blue - Function Calls
3. Red - Variables
4. Yellow - Statements (if, else, return) and mathematical operators
5. Orange - Numeric Values and Strings


**Enjoy! :)**
